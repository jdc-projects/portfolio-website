# GitHub Runner

## Goal

To create a customised Docker image for running GitHub Actions pipelines on my homelab.
The image will based on the existing GitHub [runner image](https://github.com/actions/runner), with some extra tools and utilities installed:

- [Node.js](https://nodejs.org/), runtime used by multiple GitHub Actions actions
- [yq](https://github.com/mikefarah/yq), a yaml and json query tool

The image will be run on my homelab, on Kubernetes, using the GitHub [Actions Runner Controller (ARC)](https://github.com/actions/actions-runner-controller).

## Technology

- [Docker](https://www.docker.com/), software for building and running containers
- [GitHub Actions](https://github.com/features/actions), a CI/CD platform
- GitHub [Actions Runner Controller](https://github.com/actions/actions-runner-controller), hosting GitHub Actions runners on Kubernetes

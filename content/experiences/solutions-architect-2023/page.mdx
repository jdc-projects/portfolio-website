# Solutions Architect (Credera, FS Client)

Jack worked on a customer data migration application, linking two external systems using a cloud-native application built around Azure Data Factory.
He also supported the development and deployment of a tactical solution for fast-tracked delivery of client data migration.

- Organised the deployments of the solution to the client's environment, managing remediation where necessary
- Oversaw the ingestion of clients into the new solution, ~90,000 clients with an average account value of ~£2.3m
- Created architecture diagrams and decisions for the system, such as infrastructure and data entity relationships
- Documented intended behaviour, such as filtering criteria for  types of customers, for review and approval before use
- Prepared, facilitated, and presented the project conclusion presentation, and weekly meetings, with stakeholders
- Extracted information about the customer population for analysis and documentation using SQL
